# Day 17 (2026-11-17): DAG design: retries, backfill, SLA

## 1. Key Concepts
- Idempotent Task Design: Using logical execution_date instead of CURRENT_DATE to ensure deterministic reruns.
- Sensor & Worker Optimization: Using mode="reschedule" to free worker slots during long-running waiting periods.
- Task Flow API & TaskGroups: Clean dependency grouping without bloated XCom serializations.

## 2. Failure Modes & Mitigations
- ⚠️ Catchup Storms: Leaving catchup=True on newly unpaused DAGs triggering hundreds of concurrent executions.
- ⚠️ XCom Overload: Passing heavy dataframes through Airflow metadata database rather than GCS URIs.

## 3. Interview Preparation
### Q: How do you handle backfills and avoid duplicate data in Cloud Composer / Airflow?
> "Ensure every task is idempotent: writes to BigQuery should use WRITE_TRUNCATE on specific partition bounds or MERGE statements. Always test DAGs with execution_date parameterization."
